# 🎮 JavaScript Mini-Games Collection

### Краткое описание
Учебный проект (курсовая работа), представляющий собой адаптивный веб-сайт с коллекцией из **6 интерактивных браузерных мини-игр**.
Проект разработан с целью демонстрации навыков работы с логикой JavaScript, манипуляций с DOM-деревом и обработки пользовательских событий.

**В состав коллекции входят игры:**
* 🔢 **Угадай число** — игра на поиск случайного числа от 1 до 100.
* 🧮 **Простая арифметика** — генератор случайных математических задач.
* 🔄 **Переверни текст** — утилита, инвертирующая введенную строку.
* 🧠 **Простая викторина** — тест с вариантами ответов.
* ✂️ **Камень, ножницы, бумага** — классическая игра против компьютера.
* 🎨 **Генератор случайных цветов** — интерактивное изменение фона страницы.

---

### Используемые технологии
* **HTML5** — семантическая разметка структуры сайта.
* **CSS3** — стилизация интерфейса, сетки (Flexbox/Grid), адаптивная верстка под мобильные устройства.
* **JavaScript (ES6+)** — логика всех игр, работа с алгоритмами, генерация случайных чисел и динамическое обновление интерфейса через DOM API.
